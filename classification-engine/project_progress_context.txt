1. PROJECT OVERVIEW & PURPOSE
--------------------------------------------------------------------------------
The Standalone AI Classification Engine is a lightweight, modular, production-grade 
Python 3.11+ microservice built using FastAPI, Pydantic v2, and Ollama (Gemma 3 4B).

Its sole responsibility is receiving unstructured societal problem submissions from 
citizens, analyzing the input text using LLM reasoning, validating output against a 
strict controlled taxonomy and business rules, evaluating AI confidence, and returning 
a structured machine-readable JSON classification.

Key Principle: The engine is AI-assisted. High-confidence results (>= 0.85) are marked 
as "classified", while ambiguous/low-confidence results (< 0.85) are marked as 
"review_required" for human review. AI never makes irreversible real-world decisions.

4. DATA CONTRACTS (PYDANTIC V2)
--------------------------------------------------------------------------------
Input Model (app/schemas/input.py):
- ProblemLocation: district (str, required), state (str, required), latitude (float, optional -90 to 90), longitude (float, optional -180 to 180).
- ProblemClassificationInput: problemId (str, required), title (str, required), description (str, required), location (ProblemLocation). Includes field trimming and non-empty validation.

Output Models (app/schemas/classification.py):
- ClassificationResult:
    * problemSummary: str
    * primaryDomain: str (must be in controlled taxonomy)
    * secondaryDomains: list[str]
    * subcategory: str (must belong to primaryDomain)
    * severity: LOW | MEDIUM | HIGH | CRITICAL
    * urgency: LOW | MEDIUM | HIGH | CRITICAL
    * researchRequired: bool
    * governmentActionPossible: bool
    * requiredExpertise: list[str]
    * requiredResources: list[str]
    * confidence: float (0.0 to 1.0)
    * reasoning: str
- ClassificationResponse:
    * problemId: str
    * status: classified | review_required | failed
    * classification: Optional[ClassificationResult]
    * error: Optional[ErrorDetails]

5. CONFIDENCE EVALUATION RULES
--------------------------------------------------------------------------------
Defined in app/services/confidence.py & app/config.py:
- AI_HIGH_CONFIDENCE_THRESHOLD = 0.85
- AI_REVIEW_THRESHOLD = 0.60

Logic:
If confidence >= 0.85 -> status = "classified"
If confidence < 0.85  -> status = "review_required"

8. HOW TO RUN & TEST THE SERVICE
--------------------------------------------------------------------------------
1. Navigate to directory:
   cd classification-engine

2. Create & activate virtual environment:
   python -m venv .venv
   .venv\Scripts\Activate.ps1   (Windows PowerShell)

3. Install requirements:
   pip install -r requirements.txt

4. Run unit tests:
   pytest -v

5. Start FastAPI server:
   uvicorn app.main:app --reload --port 8000
